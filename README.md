# Christmas Memory Card Game

A simple and interactive **memory matching game** built with HTML, CSS, and JavaScript.

---

## Overview

Flip cards to find matching pairs. The game tracks your **moves** and **time**, challenging your memory and speed.

---

## Features

* 4x4 memory card grid (8 pairs)
* Flip animation (CSS 3D transform)
* Timer + move counter
* Restart button
* Supports custom images (fallback to emoji if not available)

---

## How to Run

1. Open `index.html` in your browser
2. Click cards to start playing
3. Match all pairs to win 🎉

---

## Optional Assets

```
images/
│── 1.png → 8.png   # card images
│── back.png        # card back
```

---

## Customization

* Change emojis in `EMOJI`
* Change grid size via `PAIRS`
* Replace images in `/images` folder

---

## Goal

Match all pairs with the **fewest moves** and **fastest time**.
